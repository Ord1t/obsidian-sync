Privacy Policy

Last updated: November 14, 2026

1. Overview

Obsidian Sync is a personal application used to synchronize Obsidian notes with Google Drive through the GSync plugin.

2. Google Drive Access

The application requests Google Drive access to upload, download, update, and delete files necessary for note synchronization.

3. Data Storage

Notes are stored locally on the user's devices and in the user's own Google Drive account. This application does not operate a separate server for storing note content.

4. Data Sharing

The application does not sell personal data or intentionally share note content with advertisers or third parties. Google processes data as the cloud provider.

5. Security

Data is transferred using HTTPS. This configuration does not provide end-to-end encryption of note files.

6. User Control

The user can delete synchronized files from Google Drive and revoke application access through Google Account settings.

7. Contact

For privacy-related questions, contact the application owner through the GitHub repository.
